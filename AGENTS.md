# Agent Instructions

## Simplified Technical English

Use ASD-STE100 (Simplified Technical English) for all prose you write.
This includes user messages, documentation, code comments, commit messages,
test descriptions, and messages to other agents.

- Use short, direct sentences.
- Use active voice.
- Give one instruction in each sentence.
- Use the same term for the same item.
- Do not use idioms, vague words, or unnecessary jargon.
- Keep required technical terms when a simpler term can reduce accuracy.

Follow higher-priority instructions when they conflict with this file.
